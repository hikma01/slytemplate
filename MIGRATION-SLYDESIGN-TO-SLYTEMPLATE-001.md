# SlyDesign → SlyTemplate — Naming Migration

```yaml
mission_id: SLYTEMPLATE-NAMING-MIGRATION-001
old_canonical_name: SlyDesign
new_canonical_name: SlyTemplate
architecture_change: NO
historical_identity_preserved: YES
```

SlyTemplate est le nom canonique actif du module de résolution de templates,
binding, composition et production du `PresentationTree`. Les identifiants,
preuves et missions historiques portant `SLYDESIGN` restent inchangés afin de
préserver leur intégrité.

`SlyDesign = FORMER_NAME_OF SlyTemplate`.

Les surfaces actives, chemins de projet, packages et projections
d'observabilité utilisent `SlyTemplate`. Les anciennes télémétries restent
interprétables sous leur nom original ; aucune donnée historique n'est réécrite.

Le mot « design » reste autorisé lorsqu'il désigne réellement le design visuel,
les tokens, une policy graphique ou un artefact de conception.
